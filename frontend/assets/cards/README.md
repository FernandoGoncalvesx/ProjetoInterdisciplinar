# Recursos dos cards

O primeiro modelo é desenhado em canvas por frontend/js/editor-card.js.
Isso permite exportar nome e posição editáveis sem textos gravados no fundo.
A configuração de dimensões está em backend/models/card.py.

Os PNGs na pasta cards/ da raiz são referências e permanecem intactos.
Esta pasta poderá receber fundo e moldura separados para uma versão visual posterior.
Não colocar fotos de usuários nesta pasta pública.
